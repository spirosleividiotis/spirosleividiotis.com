# One-time setup: so Cursor can push for you

Right now `git push` from this repo uses your **work (Qonto) GitHub** and gets "Permission denied". To have every change pushed live automatically, this repo must use your **personal GitHub** (spirosleividiotis).

## Option A – Use SSH (recommended)

1. **Use a personal SSH key for GitHub**  
   If you don’t have one: [GitHub: Generating a new SSH key](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key). Add the **public** key to your **personal** GitHub account (Settings → SSH and GPG keys).

2. **Point this repo at GitHub over SSH** (run once in this folder):
   ```bash
   cd "/Volumes/Spiros Leividiotis LaCie/Qonto backup/1portfolio-website/spirosleividiotis.com"
   git remote set-url origin git@github.com:spirosleividiotis/spirosleividiotis.com.git
   ```

3. **Test:** run `git push origin main`. If it works, from then on Cursor can run the same command and your site will go live after each change.

## Option B – Use GitHub CLI (personal account)

1. Install GitHub CLI (`brew install gh` if needed).
2. In Terminal, run: `gh auth login` and log in with your **personal** account (spirosleividiotis).
3. For this repo only, use the credential helper so Git uses that login:
   ```bash
   cd "/Volumes/Spiros Leividiotis LaCie/Qonto backup/1portfolio-website/spirosleividiotis.com"
   gh auth setup-git
   ```
4. Run `git push origin main` once to confirm. After that, Cursor can run it for you.

---

Once either option works, tell Cursor: “push live” or “deploy” after edits and it will run `git add`, `git commit`, and `git push` for you.
